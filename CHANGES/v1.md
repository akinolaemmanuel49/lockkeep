# v1 — Initial Encrypted Personal Vault

Baseline release: a zero-knowledge personal vault with authentication and a
Vite + React frontend backed by a Go (Gin) API.

## Added

- **Encrypted personal vault.** Secret values are sealed client-side with
  AES-256-GCM before they leave the browser; the server only ever stores and
  returns ciphertext.
- **Key derivation.** scrypt / argon2id, negotiated via a server crypto-policy,
  with a per-user verification hash used to confirm the unlock key.
- **Authentication.** Local username/password sign-up and sign-in, plus OAuth
  (Auth0) sign-in.
- **Sessions.** Short-lived access tokens with refresh-token rotation.
- **Deployment.** MongoDB replica set, Traefik routing, and docker-compose for
  the API and web services.

## Notes

- Structure duplicated as separate frontend and backend subtrees; both were
  vendored into this repository so the project can be built from a single tree.
